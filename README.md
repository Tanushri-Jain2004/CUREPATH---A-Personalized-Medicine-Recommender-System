
# CurePath – AI Based Disease Prediction and Healthcare Guidance System

## Overview

CurePath is an intelligent healthcare guidance system developed using Machine Learning and Flask. The system predicts possible diseases based on symptoms entered by the user and provides detailed healthcare guidance including precautions, medications, diet recommendations, and workout suggestions.

The primary objective of CurePath is to help users identify potential diseases at an early stage and encourage timely medical consultation. The project combines Artificial Intelligence with healthcare knowledge to provide quick, accessible, and user-friendly healthcare support.

---

## Features

- Disease prediction using Machine Learning
- Symptom-based health analysis
- Precautions and prevention guidance
- Medication suggestions with dosage information
- Diet recommendations
- Workout and fitness recommendations
- Interactive chatbot support
- Search history management
- Responsive user interface using Bootstrap

## Project Modules

### 1. User Module
Allows users to enter symptoms and receive disease predictions along with healthcare guidance.

### 2. Disease Prediction Module
Uses a trained Random Forest Machine Learning model to analyze symptoms and predict possible diseases.

### 3. Healthcare Guidance Module
Provides:
- Precautions
- Medication suggestions
- Diet plans
- Workout recommendations

### 4. Search History Module
Stores previous searches and prediction history for users.

### 5. Information Module
Displays healthcare-related information and project details.
